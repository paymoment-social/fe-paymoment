# Brand — PayMoment

_Status: active_

PayMoment is a premium, dark-first social layer for the PayBox ecosystem. The visual source of truth is the supplied 1536 × 1024 product design.

## Palette

- Canvas: `#08090A`
- Raised surface: `#101113`
- Elevated surface: `#17181B`
- Primary text: `#F5F5F7`
- Secondary text: `#A6A6AD`
- Hairline border: `#292A2F`
- Brand lilac: `#B8A2FF`
- Brand violet: `#8056E8`
- Positive: `#53D39A`
- Destructive: `#FF6B7D`

## Typography

Use Geist for interface and editorial copy. Use Geist Mono with tabular numerals for Box balances, reward amounts, and leaderboard totals.

## Voice

Confident, concise, optimistic, and human. Product terminology uses **Moment** for posts and **Box** for earned rewards.

## Visual rules

- Dark mode is the canonical experience.
- Use thin borders instead of heavy shadows.
- Cards use restrained 14–16 px radii; controls use 10–12 px radii or pills.
- Keep one accent family: lilac to violet.
- Desktop layout uses a left navigation rail, centered feed, and contextual right rail.
- Mobile layout uses a sticky header and bottom navigation while preserving the feed hierarchy.
